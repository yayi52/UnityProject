# 2D 橫向捲軸殭屍射擊遊戲 (2D Zombie Side-Scroller)

這是一款使用 Unity 引擎開發的 2D 橫向捲軸殭屍射擊遊戲。玩家需要在充滿挑戰的關卡中生存下來，擊敗不斷來襲的殭屍，並達成各關卡的勝利條件。

---

## 核心功能 (Features)

### 玩法與系統
- **多樣化戰鬥與角色控制**: 流暢的 2D 角色控制器，整合了移動、跳躍及多種動畫狀態。支援多種武器（手槍、散彈槍、機關槍）的戰鬥系統，包含了彈藥管理與射擊邏輯。
- **動態 AI 生成與關卡進程**: 敵人會根據關卡設定動態生成，並具備自動追蹤玩家的基礎 AI。遊戲擁有多個關卡，包含「殲滅所有敵人」以及在限定時間內存活的「生存挑戰模式」等不同勝利條件。

### 技術架構
- **完整的存檔與讀檔系統 (Save/Load System)**: 開發了一套穩健的資料持久化功能，能夠將玩家的遊戲進度（包含生命值、彈藥庫存、所在位置等）序列化為檔案，讓玩家可以隨時讀取並恢復遊戲。
- **事件驅動的模組化設計**: 採用 `UnityEvent` 開發了如 `Health` (通用生命值) 等可重複使用的通用組件。此設計將核心數值邏輯與 UI 顯示分離，大幅降低了程式碼的耦合度，提高了系統的擴展性與可維護性。
- **中央化遊戲狀態管理**: 透過一個全域靜態類別來統一管理遊戲的核心狀態（如遊戲難度、分數、剩餘敵人數等），確保資料在不同場景與遊戲系統之間傳遞的一致性。
- **動態 UI 系統**: UI 介面能即時反應遊戲狀態的變化，例如動態更新玩家血條、彈藥數量，並在場景轉換時提供流暢的淡入淡出動畫。

## 操作方式 (Controls)

| 按鍵 | 功能 |
|---|---|
| **A / D** | 向左 / 向右移動 |
| **R** | 換子彈 |
| **Space** | 跳躍  |
| **滑鼠左鍵** | 射擊  |
| **數字鍵 1, 2, 3** | 切換武器  |
| **Esc** | 暫停 / 打開選單 |
